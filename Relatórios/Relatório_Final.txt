Hoje foi iniciado o desenvolvimento do projeto de Trabalho de Conclusão de Curso (TCC), cujo objetivo é realizar a classificação de tumores cerebrais em imagens de ressonância magnética utilizando técnicas de transferência de aprendizado (Transfer Learning).

O projeto realizará uma análise comparativa dos modelos utilizados, considerando aspectos como desempenho na classificação, eficiência computacional e explicabilidade dos resultados. Para organizar o desenvolvimento e facilitar o acompanhamento do projeto, o trabalho foi dividido em diferentes etapas.

1.1 - Configuração do ambiente de desenvolvimento

Inicialmente, foi definido o Visual Studio Code (VS Code) como ambiente de desenvolvimento do projeto. O ambiente será configurado para utilização da linguagem Python e das bibliotecas necessárias para processamento, análise e visualização dos dados.

Nesta etapa, serão instaladas inicialmente as seguintes bibliotecas:
 - Pillow: manipulação e processamento de imagens;
 - ImageHash: geração e comparação de hashes de imagens;
 - pandas: organização, manipulação e análise dos dados;
 - NetworkX: criação e análise de estruturas baseadas em grafos;
 - Matplotlib: geração de gráficos e visualização dos dados.

Essas bibliotecas serão utilizadas ao longo das próximas etapas do desenvolvimento, principalmente durante a organização e análise do conjunto de dados, processamento das imagens e visualização dos resultados.

1.1.1 - Criação do ambiente virtual

Foi criado um ambiente virtual Python (.venv) específico para o projeto, com o objetivo de isolar suas dependências.

Comando utilizado:
python -m venv .venv

1.1.2 - Instalação das dependências

Comando utilizado:
python -m pip install pillow imagehash pandas networkx matplotlib

Resultado:
Todas as bibliotecas e suas respectivas dependências foram instaladas com sucesso no ambiente virtual. Após a instalação, foi gerado o arquivo requirements.txt, contendo as versões das dependências utilizadas no projeto, permitindo a reprodução futura do ambiente de desenvolvimento.

Comando utilizado:
python -m pip freeze > requirements.txt
